### Genetic Transformer: An Innovative Large Language Model Driven Approach for Rapid and Accurate Identification of Causative Variants in Rare Genetic Diseases


- **GeneT-qwen0.5b-public-mode.tar.gz**: The GeneT model trained on public data, with the base LLM model being qwen1.5-0.5B.
- **GeneT.gz**: Prediction results of GeneT for all possible non-synonymous single-nucleotide variants in dbNSFP.
- **infer-GeneT.sh**: Example script for training the GeneT model.
- **train-GeneT.sh**: Example script for inference using the GeneT model.
